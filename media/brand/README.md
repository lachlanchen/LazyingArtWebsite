# LazyingArt introduction

An intentionally silent, 12-second introduction: the approved seated-panda
banner, the app family, and Lala, Aya, Sasa and Zhuangzi. The website address
stays visible throughout. Made with LocalVideoGen's CPU motion-composition
workflow using existing approved artwork and real app icons; no generated
interface or simulated product performance.

- [GIF](lazyingart-intro.gif): 960 × 540, 180 frames, infinite loop, 2.26 MiB.
- [MP4 master](lazyingart-intro.mp4): 960 × 540, 30 fps, 12 seconds, no audio.
- [Static preview](lazyingart-intro-poster.png).

The GIF is a separate asset from the original static banner, which remains
unchanged at its existing URL. Use this shared GIF as the visible masthead;
clicking it opens the website. Earlier forks and clones can keep using
`https://github.com/lachlanchen/lachlanchen/raw/main/figs/banner.png`:
