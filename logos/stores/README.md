# Store artwork

- `app-store.png`: [Apple's App Store icon](https://developer.apple.com/assets/elements/icons/app-store/app-store-128x128_2x.png), unaltered.
- `google-play.svg`: Google's multicolor Play mark, with unaltered paths from the [Google Play header](https://play.google.com/store/apps).

Used to identify links to the respective stores, not to imply endorsement.
Text labels remain visible and accessible without artwork or JavaScript.
