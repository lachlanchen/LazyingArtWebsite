# LazyingArt seated panda

Website exports of the approved September 27, 2026 panda. Full source, prompts, app-icon files and rebuild instructions: [shared brand kit](https://github.com/lachlanchen/lachlanchen/tree/main/logos/panda-v1).

The full panda is used for headers and home-screen icons. The closer face derivative is used for browser favicons. The prior primary logo/favicon files are archived in `../legacy/`; old SVG/wordmark files are historical artwork, not vectors of the new panda.
