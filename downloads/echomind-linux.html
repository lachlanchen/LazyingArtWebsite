Native desktop preview

EchoMind for Ubuntu and Linux

Read posts, chat with friends and groups, and pick up an Agent conversation in a desktop window. Saved language cards retain their readings and grammar colors.

Version 1.0.1 Preview 1 · Tested on Ubuntu 24.04 LTS, x64 · 33.9 MB

Download Ubuntu .deb

This is a direct, unsigned preview download, not a package from Ubuntu or the Snap Store. The .NET runtime is included.

Install and open

  1. Save the .deb and compare its SHA-256 with the value below.
  2. In a terminal in the download folder, run sudo apt install ./EchoMind-1.0.1-preview.1-linux-x64.deb.
  3. Open EchoMind from the application menu.

An internet connection and an X11 or XWayland desktop are required. The package is for x64; ARM is not included. To remove it, run sudo apt remove echomind.

Sign in

Use your EchoMind username or email and password. Full access still requires an EchoMind invitation. The Linux app does not save your password or login session. Use the web app for Apple or Google sign-in, voice and attachments, or features not included in this preview. There are no in-app purchases or push notifications in this build.
