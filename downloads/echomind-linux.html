EchoMind for Ubuntu and Linux

Message friends and groups, read posts, or pick up a workspace task with Agent. Group links open in the same window without replacing the message you’re writing.

Version 1.0.45 Preview 1 · Package revision 2 · Tested on Ubuntu 24.04 LTS, x64 · 35.0 MB

Download Ubuntu .deb

This is a direct, unsigned preview download, not a package from Ubuntu or the Snap Store. The .NET runtime is included.

Install and open

  1. Save the .deb and compare its SHA-256 with the value below.
  2. In a terminal in the download folder, run sudo apt install ./EchoMind-1.0.45-preview.1-2-linux-x64.deb.
  3. Open EchoMind from the application menu.

An internet connection and an X11 or XWayland desktop are required. The package is for x64; ARM is not included. To remove it, run sudo apt remove echomind.

Sign in

Sign in with your EchoMind username or email and password. To use Apple or Google, open the web app; that session stays in your browser.
