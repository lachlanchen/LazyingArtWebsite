Install on Ubuntu

These Debian packages were tested on Ubuntu 24.04 LTS (x86-64). Open the downloaded file in your package installer, or run sudo apt install ./filename.deb from your Downloads folder. Replace filename.deb with the actual file name. The apps appear in your launcher after installation.

The libraries use the live reading services. Use the app menu to check for desktop package updates.
