# Musia Android launch — October 5, 2026

Musia: Learn Music & Guitar **0.1.1 (2)** is published on Google Play.
The release owner records an active full rollout across 172 countries/regions.
The public US listing independently identifies the exact app and reports an
InStock **USD 2.99** offer.

[Google Play](https://play.google.com/store/apps/details?id=art.lazying.musia)
· [Practice tools](https://musia.lazying.art/)

The website adds the app's actual store icon, a launcher shortcut and a purchase
button. A separate product-directory entry keeps the native practice app
distinct from the existing Fun music library and desktop generation tools.
Homepage practice and review-status copy is localized in all 13 site languages.

The shipping app supports pitch-preserving speed adjustment, phrase loops,
timed lyrics, guitar chord diagrams, rhythm practice and device-local history.
Streaming songs requires internet; analyzed music annotations are estimates.
No account or subscription is required. This release does not offer microphone
assessment, user-upload analysis or cloud music generation.

Apple iOS and macOS remain **Waiting for Review** in the owner handoff.
There is no public Apple download button for Musia. Store availability is not
an installation, customer result or revenue event.
