# Musia Mac release — October 12, 2026

Musia 0.1.2 (4) is public on the Mac App Store. The production owner released
the approved version and verified READY_FOR_SALE. A fresh public US store
page independently confirms the app identity, Mac compatibility and USD 2.99.
It requires macOS 14 or later and supports Intel and Apple silicon.

- [Mac App Store](https://apps.apple.com/us/app/musia-learn-music-guitar/id6816265930?mt=12)
- [Google Play](https://play.google.com/store/apps/details?id=art.lazying.musia)

The iPhone/iPad edition remains in review. Later creator/agent-mode builds
are not this public Mac release. This update adds a specifically labelled
Mac purchase button, preserves Android, and corrects all 13 homepage locales
plus the generated product directory. No pricing or store submission changed.

Release authority: Musia's `store/macos-release-2026-10-12.md`. Public evidence:
the Apple listing's SoftwareApplication data and the release owner's real Mac
App Store screenshot. Platform hub copy uses the same bounded release facts.

The practice app uses a built-in Em/Am reference exercise, phrase loops,
pitch-preserving slowdown and guitar fingerings. Catalog chord analysis is an
estimate, not a verified score. There is no microphone performance grading.
